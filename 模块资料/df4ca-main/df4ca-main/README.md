# STM32CubeMX配置HX711压力传感器模块串口输出数据并屏幕显示（HAL库）

## 项目描述

本项目旨在通过STM32CubeMX工具配置HX711压力传感器模块，实现压力数据的采集与处理，并通过串口输出数据，同时在8针1.3寸带字库的OLED屏幕上实时显示重量信息。项目适用于量程为5Kg的压力传感器，使用HAL库进行开发。

## 功能特点

- **压力传感器数据采集**：使用HX711芯片进行高精度数据采集，支持24位A/D转换。
- **串口输出**：通过串口将采集到的重量数据输出，便于使用电脑串口助手实时查看。
- **屏幕显示**：通过8针1.3寸带字库的OLED屏幕实时显示重量信息。
- **皮重校准**：程序中实现了皮重校准功能，用户可以根据实际测量结果调整系数，以提高测量精度。

## 硬件连接

### 压力传感器连接
- VCC：5V
- DT：PA5
- SCK：PA6

### 串口1带字库OLED屏幕连接
- VCC：3.3V
- CLK：PB3
- MOSI：PB4
- DC：PB5
- CS1：PB6
- FS0：PB7
- CS2：PB8

## 使用说明

1. **硬件初始化**：使用STM32CubeMX配置硬件端口，生成初始化代码。
2. **皮重校准**：程序启动时会自动获取一个初始重量作为皮重，实际重量为后续检测值减去皮重。
3. **系数调整**：程序中定义了`#define GapValue x`，用户可以根据实际测量结果调整该值以校准重量。如果测量结果偏大，增加该值；如果测量结果偏小，减小该值。
4. **数据输出与显示**：通过串口输出重量数据，并在OLED屏幕上实时显示。

## 注意事项

- 确保硬件连接正确，特别是电源电压和信号线的连接。
- 在调整系数时，建议进行多次测量以获得更准确的校准结果。
- 如果遇到数据异常，检查硬件连接和程序配置是否正确。
